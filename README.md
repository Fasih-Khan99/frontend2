# Responsive Home Page (HTML + CSS)
## This is a simple responsive home page built with HTML and Vanilla CSS, featuring the following:

## Features
- Responsive layout using Flexbox
- Clean, minimal design
- Works on desktop, tablet, and mobile

## Tech Stack
- HTML
- Vanilla CSS

## Installation
(1) Clone this repository to your local machine by running the following command in VS Code Terminal:
- git clone https://github.com/Fasih-Khan99/frontend2.git
 
(2) Navigate to the project directory by running the following command in VS Code Terminal:
- cd frontend2

(3) Move to Master branch by running the following commands in VS Code Terminal:
- git branch -a
- git checkout master
- git pull origin master

(4) Run the index.html file in any browser:
- Right click on index.html, then click on open with followed by your desired browser.
